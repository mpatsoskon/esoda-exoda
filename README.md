# Έσοδα-Έξοδα myDATA

> *English:* A local web app for Greek freelancers: it downloads income/expense books from
> AADE's myDATA, helps classify expenses, transmits invoice types 13.3/14.x/17.2, and builds
> the E3 and VAT summaries. Greek-language UI and docs. AGPL-3.0.

Τοπική εφαρμογή για ελεύθερους επαγγελματίες: κατεβάζει τα βιβλία εσόδων-εξόδων από το myDATA,
βοηθά στον χαρακτηρισμό των εξόδων, διαβιβάζει παραστατικά (13.3, 14.x, 17.2) και φτιάχνει τις
συνόψεις Ε3 και ΦΠΑ. Τρέχει στον υπολογιστή σου· τα δεδομένα μένουν σε ένα τοπικό αρχείο SQLite.

> **⚠️ Προσοχή**
> - Κάθε διαβίβαση στο **production** myDATA είναι **αμετάκλητη**.
> - Το εργαλείο **δεν αντικαθιστά τον λογιστή σου**. Έλεγξε κάθε χαρακτηρισμό.
> - Παρέχεται **χωρίς καμία εγγύηση** (βλ. LICENSE).

## Για ποιον είναι
Ελεύθεροι επαγγελματίες **παροχής υπηρεσιών** με **απλογραφικά** βιβλία. Οι κωδικοί Ε3 και τα
έτοιμα πρότυπα (κοινόχρηστα 13.3, αποσβέσεις 17.2) είναι ρυθμισμένα γι' αυτή την περίπτωση.
Άλλη δραστηριότητα; Δες «Θέλουμε τη βοήθειά σου».

## Τι χρειάζεσαι
- Python 3.11 ή νεότερη (η SQLite έρχεται μαζί της· δεν χρειάζεται Docker ούτε server βάσης)
- Κλειδιά myDATA REST API (user id + subscription key) — για δοκιμές, από το δοκιμαστικό
  περιβάλλον της ΑΑΔΕ (δωρεάν εγγραφή, [φόρμα εγγραφής](https://www.aade.gr/en/mydata-electronic-books/mydata/test-environment))· για πραγματική χρήση, από το myAADE.

## Εγκατάσταση
1. `git clone https://github.com/mpatsoskon/esoda-exoda && cd esoda-exoda`
2. `python -m venv .venv`, ενεργοποίησέ το, και `pip install -e .`
3. `esoda-exoda setup` — φτιάχνει τη βάση και ρωτά ΑΦΜ, επωνυμία, ΤΚ, πόλη, περιβάλλον
   (`dev` ή `production`) και τα κλειδιά myDATA. Τα κλειδιά αποθηκεύονται στο keyring του
   λειτουργικού (Windows Credential Manager / macOS Keychain / Secret Service), όχι σε αρχείο.
   Αν άλλαξαν τα κλειδιά myDATA (ή σε νέο υπολογιστή): `esoda-exoda keys`.
4. `esoda-exoda` και άνοιξε το http://127.0.0.1:8000

## Η βάση και το backup
Όλα τα δεδομένα είναι σε ένα αρχείο SQLite: το `[database] path` του `config.toml`, σχετικό με
το `data_dir` (από προεπιλογή `esoda_exoda.sqlite3` δίπλα στο `config.toml`). Το αρχείο είναι στο
`.gitignore`· μην το ανεβάσεις ποτέ, γιατί κρατά όλα τα βιβλία σου.

Για αντίγραφο: `esoda-exoda backup <αρχείο>`, π.χ. `esoda-exoda backup backup-2026-07.sqlite3`.
Δουλεύει και όσο τρέχει η εφαρμογή. Μην αντιγράφεις σκέτο το αρχείο όσο τρέχει: ένα μέρος
των αλλαγών ζει στο `-wal` δίπλα του και θα χαθεί.

## Από την παλιά Postgres
Αν είχες ήδη την έκδοση με Postgres σε Docker, μετέφερε τα δεδομένα μία φορά:
1. Σήκωσε την παλιά βάση (`docker compose up -d` στην παλιά έκδοση του repo) και τρέξε μία φορά
   την παλιά εφαρμογή, ώστε το σχήμα της να είναι στην έκδοση 2.
2. `pip install -e .[postgres]`
3. `python scripts/migrate_from_postgres.py` — ρωτά τον κωδικό της Postgres και γράφει νέο
   αρχείο στο `[database] path`. Με `--dsn` δίνεις άλλη βάση, και με ένα όρισμα άλλο αρχείο.
4. Το script τυπώνει πλήθη γραμμών και αθροίσματα ποσών ανά πίνακα, πριν και μετά. Αν κάτι δεν
   συμφωνεί, σβήνει το νέο αρχείο· την Postgres δεν την αλλάζει ποτέ.

Ο κωδικός της βάσης δεν χρειάζεται πια. Αν θέλεις, σβήσε τον από το keyring (service
`esoda-exoda-db`).

## Δοκιμαστικό ή πραγματικό myDATA
Το περιβάλλον επιλέγεται μία φορά στο `setup` και δένεται με τη βάση. Ξεκίνα με `dev`.
Για να έχεις και τα δύο, φτιάξε δεύτερο config με άλλο `[database] path`, και δείξε το
με τη μεταβλητή `ESODA_EXODA_CONFIG=<path>`. Η μπάρα στην κορυφή κάθε σελίδας δείχνει σε ποιο
περιβάλλον βρίσκεσαι.
